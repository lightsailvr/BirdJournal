## Phone test

The clean review Debug build (`fbbc2dc`, 0.1.0; subsequent changes are tests, evidence and Cloud build-number processing) is installed on the connected phone after profiling, preserving its 37 sightings and five packs. Use the real account. Try the following before merging:

1. Force quit and reopen. Listen should become usable quickly; if loading is slow, it should show an updating progress indicator. Open a widget patch or Guild invitation from a terminated app if available, and confirm it reaches the intended page.
2. Open a patch. Turn it over and back using both the patch and its button, including quick reversals. Repeat with Reduce Motion enabled: captions, button words and card faces must never overlap.
3. Scroll well down Species, switch to Sightings, then try the other Journal modes. Each switch must show the destination's first rows immediately. A patch page and back, and search/clear, should retain the current mode's place.
4. Open the species page from Species. Check a large centred patch, a carousel for several editions (a reading column at accessibility sizes), the prominent Atlas action, and inline sightings that each open their record. Check an unfound LA bird in the Atlas for its silhouette; the glyph remains expected in other packs without silhouettes.
5. Inspect the Canada Goose in the Guild feed, its Find page, Compare and goals. Borrowed local artwork is labelled on detailed surfaces. If there is no goose entry, or only a repeat line, report that separately: the artwork fallback does not resend or backfill finds.
6. Check Settings → Version for 0.1.0 and the local commit.

**Guild service check (backend deployed):** create a Guild with an icon, reopen it as creator, rename/change the icon, and confirm it persists and appears in an invitation. A noncreator must have no Edit Guild control. Include this in the phone smoke test.
