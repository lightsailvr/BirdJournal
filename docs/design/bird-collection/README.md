# Collectible cards design handoff

The editable specification is [style-guide.md](style-guide.md).

Generated deliverables are kept out of the repository (about 30 MB): the maintainer's copy is in `output/pdf/birdjournal-collectible-cards-style-guide.pdf` and `output/bird-collection/` (the PDF, an interactive prototype and art references) at the root of their checkout, and the distribution archive is `output/birdjournal-collection-handoff.zip`.

The 0.2 design replaces encounter tabs with a species gallery and specifies a physical two-sided card flip. This is a visual and interaction reference, not an application implementation.
